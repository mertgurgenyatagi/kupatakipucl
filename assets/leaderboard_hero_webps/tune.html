Hero Photo Tuner

Each frame is the same 2:3 (width:height) portrait box the hero carousel renders. Drag the sliders to set position and zoom for each photo, then export. Zoom is simulated here with a CSS scale, but gets applied as a tighter source crop in the real pipeline — so the shipped image stays full quality at any zoom level, it doesn't get blurrier the way this on-screen preview would past 1.0×.
