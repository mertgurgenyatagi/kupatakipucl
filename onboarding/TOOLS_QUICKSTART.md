# Your Tools — Quickstart

## Serena MCP
Nothing to do — it's a background MCP server. Just ask Claude to find/rename/refactor something in a codebase; it'll use Serena automatically.

## ccusage
Run `ccusage daily` (or `weekly` / `monthly` / `blocks`) in any terminal to see your Claude Code token usage and cost.

## Frontend Design
Nothing to activate — it kicks in automatically whenever Claude writes UI/frontend code.

## Playwright
Nothing to do — ask Claude to "check it in a browser" or "test this page" and it'll drive a real browser via Playwright automatically.

## Claude Context (LanceDB)
Nothing to do — runs on local Ollama, no API key, no cost. Ask Claude to "index this codebase" once, then search in plain English ("find the auth logic").

## Superpowers
For a big feature build, type `/superpowers:brainstorm` to kick off the guided plan → build → review workflow instead of diving straight into code.
